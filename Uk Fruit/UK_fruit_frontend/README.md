# UK Fruit Dashboard

A React dashboard for monitoring UK Fruit operations. It includes summary
metrics, a revenue chart, order activity, recent orders, and sidebar navigation.
The interface is built with reusable React components.

## Component library

The dashboard uses [MUI (Material UI)](https://mui.com/material-ui/) version
9.5.0 and [MUI icons](https://mui.com/material-ui/material-icons/).
Its layout was informed by the
[MUI Dashboard template](https://github.com/mui/material-ui/tree/v9.5.0/docs/data/material/getting-started/templates/dashboard),
adapted to the UK Fruit design.

## Start the app

From this project folder, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Typecheck and production build

```powershell
npm run typecheck
npm run build
```
